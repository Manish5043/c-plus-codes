## 🚀 How to Run

### Prerequisites

- A C++ compiler (e.g., GCC, Clang)

### Compilation and Execution

1. Clone the repository:

   `bash
   git clone https://github.com/Manish5043/c-plus-codes.git
   cd c-plus-codes
   

2. Compile a specific file:

   `bash
   g++ <filename>.cpp -o <output_name>
   ``

   For example:

   ``bash
   g++ bs.cpp -o binary_search
   `

3. Run the compiled program:

   ``bash
   ./binary_search
   `
